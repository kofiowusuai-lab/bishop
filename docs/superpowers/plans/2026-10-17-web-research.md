# Independent Bishop web research

Goal: Bishop can independently search the web, open sources and produce sourced answers through native read tools, enabled by default without another paid key.

Evidence: current runtime exposes only file/memory/skill tools. Current local install is 0.4.0 with task-monitor present and enabled; the screenshot is consistent with an older running process/session. Public DuckDuckGo Lite returned relevant search-result markup without a key. DuckDuckGo HTML returned a challenge; Bing RSS returned poor relevance, so neither is a silent fallback. No challenge bypass or invented search results.

Architecture:
- `WebError(code,message,retryable=False)` exposes only controlled diagnostic fields. `WebClient(timeout=12,max_bytes=2000000).fetch(url,headers=None)` returns `{url,status,content_type,body}` with body bytes. HTTP(S) public internet only, standard ports, no userinfo, cookies, environment proxies or credential injection. Validate every resolved address and redirect; pin the chosen public address while preserving TLS SNI/certificate hostname. Bounded redirect count, response size and socket deadlines. `read(url,max_chars=12000)` returns `{ok:true,url,title,content,content_type,truncated,retrieved_at}` for HTML/text/JSON; unsupported binary content yields WebError. Scripts/styles/forms are not executed; web content is untrusted.
- `WebSearch(client=None,provider='duckduckgo',api_key=None).search(query,limit=5)` returns `{ok:true,provider,query,results:[{title,url,snippet}],retrieved_at}`. Default DuckDuckGo Lite HTML extraction uses real result classes, preserves result order/URLs, rejects challenge pages and detects empty results. Optional explicit Brave provider uses its official API and an operator-supplied environment key. No automatic paid fallback. All error categories controlled via WebError.
- Native `web_search(query)` and `web_read(url)` are read/idempotent tools. Web failures return structured error data to the model so it can try another source within the existing step budget; they must not abort a run merely because one site blocks access. Tools return bounded valid JSON with source metadata retained. Search/page text never become system instructions.
- Default config `web.enabled=true`, `web.provider='duckduckgo'`, `web.api_key_env='BISHOP_BRAVE_SEARCH_API_KEY'`, bounded timeout/results/page text limits. Add choice-based `bishop web configure`, plus `bishop web search QUERY`, `bishop web read URL`, `bishop web status` for direct diagnostics without model inference. Built-in web-research skill guides source reading/citations, installed alongside task-monitor.

Ownership: network/page builder owns web.py + tests/test_web.py; search builder owns search.py + tests/test_search.py; root owns ToolRegistry/config/CLI/skills/runtime guidance/integration/docs/release. Exact interfaces above are integration contracts.

Verification: RED/GREEN tests for local/private addresses, mixed DNS, redirects, pinned TLS/Host handling, size/content/timeout failures, actual Lite markup fixture, challenge/no-result handling, Brave key routing, structured tool errors, disabled tools, source-preserving bounds and a real runtime search-read-answer flow using recorded/fake model outputs. Live public searches and primary-page reads verify actual network behavior without provider inference. No API key imports, paid model calls or challenge bypass. Test and package installed wheel; independent review and hosted CI gate release.
